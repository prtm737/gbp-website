Content management

Edit the website

The site is managed through Pages CMS, a browser editor connected directly to the GitHub repository. Every publish creates a commit and rebuilds the site automatically.

Open the editor →
  1. Sign in with the GitHub account that has access to the repository.
  2. Choose prtm737/gbp-website and the main branch.
  3. Edit a section, upload media, then save. The site rebuilds in about a minute.

This page is not indexed by search engines. Contact the site administrator if you need editor access.
